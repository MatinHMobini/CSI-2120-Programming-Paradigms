## About the Course

This repository contains programming assignments, projects, and exercises for **CSI2120 - Programming Paradigms**, a core course at the University of Ottawa. This course covers the fundamental concepts of various programming paradigms, including functional, procedural, object-oriented, and logic-based programming.

---

## Course Topics

- **Functional Programming**
- **Object-Oriented Programming**
- **Procedural Programming**
- **Logic Programming**

---

## Technologies Used

- **Languages**: Go, Prolog, Scheme/Racket, Java, Python
- **Tools**: VS Code, IntelliJ, Git
